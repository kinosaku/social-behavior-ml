# 传播级联实验结果

评估使用上传的合成数据（synthetic data），原样保留训练、验证和测试划分。生成脚本复现了三份数据的内容指纹（content fingerprint）。详细数值、软件版本和 GIN 训练记录见 [metrics.json](metrics.json)。

## 事件分类（event classification）

测试集共 3,098 张传播图。以下分数以 0.5 为分类阈值（classification threshold）。

| 方法 | 准确率（accuracy） | 宏平均 F1（macro-F1） | 突发召回率（burst recall） | ROC-AUC |
|---|---:|---:|---:|---:|
| 多数类 | 0.6666 | 0.4000 | 0.0000 | 0.5000 |
| 仅节点数 | 0.6666 | 0.4000 | 0.0000 | 0.4880 |
| 图结构（graph structure） | 0.7308 | 0.6642 | 0.4279 | 0.7665 |
| 节点向量均值（mean node vectors） | 0.7773 | 0.7331 | 0.5557 | 0.8351 |
| 图结构＋向量均值 | 0.8225 | 0.7937 | 0.6738 | 0.8859 |
| 图同构网络（GIN） | 0.7960 | 0.7598 | 0.6118 | 0.8500 |

结构与向量拼接后，用逻辑回归（logistic regression）正确识别 1,033 个突发样本中的 696 个。测试集有 337 个突发样本漏报和 213 个正常样本误报。

## 转发来源预测（repost parent prediction）

测试集共 37,936 次排序，平均约 41 个候选。每个候选都是当前转发帖之前出现的帖子。

| 方法 | Hits@1 | Hits@5 | 平均倒数排名（MRR） |
|---|---:|---:|---:|
| 均匀随机（uniform random） | 0.0282 | 0.1408 | 0.1153 |
| 最近出现优先（recency） | 0.0256 | 0.1220 | 0.1013 |
| 已有出度优先（popularity） | 0.3465 | 0.4701 | 0.4229 |
| 逻辑回归（logistic regression） | 0.3515 | 0.4909 | 0.4339 |

当真实来源为非根节点（non-root node）时，逻辑回归的 Hits@1 为 0，Hits@5 为 0.2150。模拟数据中存在明显的根节点优势，整体排序分数应与这个分组结果一起看。
